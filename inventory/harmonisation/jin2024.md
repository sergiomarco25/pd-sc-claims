**Problem (harmonise.py, not fixed here):** every neuronal cluster is labelled "Neurons (other)" — none Excitatory or
Inhibitory — although the clusters are clearly separable (e.g. leiden_6: SLC17A7+ 88%, GAD1+ 4%; leiden_16: SLC17A7+ 12%,
GAD1+ 86%). The pan-neuronal marker set (RBFOX3, SNAP25, SYT1, STMN2) out-scores the subtype sets in
`annotate_by_markers`, so the subtype classes are never chosen. The paper's ExN (33.5%) / InN (11.0%) split is therefore
lost. Needs a fix in `annotate_by_markers` (e.g. treat "Neurons (other)" as fallback only when no neuronal subtype
score is positive), then rebuild.
Clusters with agree < 0.5: leiden_10 (Neurons, 0.39, majority Oligodendrocytes; 639 cells, likely neuron–oligo
doublets), leiden_27 (Neurons, 0.42; SLC17A7+ and GAD1+ mixed — doublets).
