# wang2024: harmonisation (GSE184950, substantia nigra)

Loader: `src/pdrep/build/wang2024.py` (adapted from `revision/scripts/06a_external_build_and_score.py::load_wang2024_sn`).
Builds: SLURM job 41861092 (no QC, superseded) → **41861603** (with paper QC, current; 160 GB, 484 s), log `logs/run_py_h_wang2024_41861603.out`.

## Sources
- Counts: 34 per-library Cell Ranger `filtered_feature_bc_matrix` folders from `GSE184950_RAW.tar`, read from the existing `external_validation/_extracted/GSE184950/`. 33,538 genes (GRCh38), Ensembl IDs in `var["gene_ids"]`.
- Donor metadata: GEO soft characteristics (brain bank donor ID, diagnosis, age, gender, race, PMI, Braak stage). Cross-checked against Table S1 (`raw/supplements/wang2024/extracted/adi8287_Tables S1 to S9.xlsx`, sheet "S1. Sample cohort"); all values agree. `GSE184950_add2.xlsx` is only the GEO metadata template, with no cell labels.
- Extra obs: `gsm`, `braak_stage_raw`, `race`.

## Libraries and donors
34 GEO libraries = 32 donors: HBNX has two libraries (p7, p9) and HBHF has two (p4, p5). Table S1 lists 23 PD-spectrum donors (6 "Parkinson's Disease" + 17 "Parkinson's Disease Dementia") and 9 controls with "Sequenced = Yes"; the extra 5 Table S1 controls (BEB…, HCT15…, HCT16HDM) were IHC-only.

## QC (applied in the loader)
The deposit holds all **457,453** pre-QC nuclei (the paper's own pre-QC number). Without QC the marker labelling failed (67k barcodes with < 200 genes; libraries D14 and D8 have median 54 and 71 genes). The loader applies the paper's first QC step (Methods: keep nuclei with 200 ≤ detected genes ≤ 2,500; paper retained 355,157) → **355,348** nuclei. The paper's later removals (doublets with scDblFinder, unstable clusters; final 315,867) cannot be reproduced from the deposit.

## Metadata decisions
- Disease: "Parkinson's Disease Dementia" → `PDD` (the source says dementia), "Parkinson's Disease" → `PD`, "Unaffected Control" → `control`. The paper analyses all 23 as PD; pool PD + PDD to reproduce it.
- `braak_lb`: the GEO/Table S1 "Braak stage" is given only for PD donors (N/A for every control), so it is read as the Lewy body (PD) Braak stage. The source does not say "Lewy" explicitly. The raw string is kept in `braak_stage_raw`.
- `sample` = GEO library title (A10, p7, …); `donor` = brain bank ID.

## Cell classes: NOT USABLE YET
No author labels → marker clustering in `finalise`. Result (21 Leiden clusters): Oligodendrocytes 285,382; Neurons (other) 29,904; Endothelial 20,133; OPCs 18,909; Astrocytes 1,020; **Microglia 0**. Cell-weighted label agreement 0.78; low clusters: leiden_17 (6,240 checked, agree 0.39), leiden_10 0.50, leiden_12 0.51, leiden_15 0.51, leiden_19 0.51.

This is wrong: the paper reports large astrocyte and microglia clusters. The cause is in `harmonise.annotate_by_markers`. Each cluster gets the argmax of the **raw mean** `score_genes` scores. In this SN dataset, ambient oligodendrocyte transcripts (MBP/PLP1/ST18) give oligodendrocyte scores of 0.4–1.1 even in astrocyte and microglia clusters, which beats the smaller dynamic range of the P2RY12/CX3CR1 or AQP4/GJA1 scores. A test that z-scored each class score across cells before the cluster mean (job 41862220) recovered about 43k astrocytes and 33k microglia. It also produced spurious labels (15.6k "Ependymal", "Pericytes"), so it is not a drop-in fix. The labelling needs a fix in harmonise.py (or a curated per-dataset label step) before wang2024 cell classes are used. Counts, donors and metadata are fine.
