## Metadata decisions
- Disease: `control` / `AD` / `PD`. Table S1 gives CDR = 0 for all four PD donors (the AD donors have CDR 3), so the paper-notes caveat that PD donors may be demented is not supported by the table; PD stays `PD`.
- `braak_lb`: Table S1 "Braak Lewy body stage" (PD 6,6,6,6; controls and AD 0).

## Cell classes
No author labels deposited → `AUTHOR_TO_CLASS = {}`, Leiden + marker labelling in `finalise`.
Classes: Oligodendrocytes 14,974; Neurons (other) 11,736; Astrocytes 6,288; Microglia 2,181; Endothelial 2,004; OPCs 1,294; Ependymal 204; Fibroblasts 148; T cells 100.
Label check (cluster label vs per-cell top marker class): cell-weighted agreement 0.894. Low-agreement clusters:
- leiden_10 (1,124 cells, labelled Oligodendrocytes, agree 0.41, cell majority Astrocytes): mixed oligo/astro cluster (likely doublets / ambient-RNA cells, consistent with no QC filtering).
- leiden_6 (126 cells, labelled Astrocytes, agree 0.44, majority Neurons (other)): small mixed cluster.
- leiden_24 (270, Neurons (other), agree 0.50).

**Known limitation (harmonise.py):** all putamen neurons end up as `Neurons (other)`; no cluster is called `MSNs` even though MSNs are the majority of striatal neurons (paper: mD1/pD1/mD2/pD2 etc.). The pan-neuronal marker set (RBFOX3, SNAP25, SYT1, STMN2) outscores the MSN set in every neuronal cluster. MSN-specific claims need a neuronal sub-labelling step (e.g. PPP1R1B/DRD1/DRD2 within the neuron class) before testing.
