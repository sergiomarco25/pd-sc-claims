# zhu2024: harmonisation (GSE202210, prefrontal cortex BA9)

Loader: `src/pdrep/build/zhu2024.py` (adapted from `revision/scripts/06a_external_build_and_score.py::load_zhu2024_pfc`).
Build: SLURM job 41860495 (96 GB, 236 s), log `logs/run_py_h_zhu2024_41860495.out`.

## Sources
- Counts: 12 per-donor 10x triplets (`GSM61063xx_<id>_{barcodes,genes,matrix}`) from `GSE202210_RAW.tar`, read from the existing `external_validation/_extracted/GSE202210/`. 33,538 genes (Cell Ranger GRCh38), Ensembl IDs in `var["gene_ids"]`.
- Donor = GEO title without the `_HHT` suffix (e.g. `hsDG142PD`; capitalisation as on GEO). One library per donor.
- Diagnosis: GEO soft (`Control` / `Parkinson's disease`).
- Sex, age, PMI, Lewy pathology score: in the paper's Table S1, which is **not on disk** (`raw/supplements/zhu2024/` is empty) → `sex`, `age`, `pmi`, `braak_lb` are NaN. GEO soft has no demographics. If Table S1 is fetched later, add it to the loader (it gives PMI only in 5/10/15 h bins and a LB+neurite score, not a Braak stage).

## Cell classes
No author labels deposited → `AUTHOR_TO_CLASS = {}`, Leiden + marker labelling in `finalise`.
Classes: Neurons (other) 34,141; Oligodendrocytes 23,867; Astrocytes 8,538; Microglia 5,235; OPCs 5,184; Fibroblasts 418; Endothelial 306; T cells 294 (paper: 276 T cells, 33 control + 243 PD; microglia 5,383).
Label check: cell-weighted agreement 0.921. Low-agreement clusters:
- leiden_0 (418 cells, labelled Fibroblasts, agree 0.33, majority Pericytes): mixed vascular-mural cluster (fibroblasts + pericytes/SMCs).
- leiden_32 (502, Microglia, 0.46) and leiden_31 (347, Oligodendrocytes, 0.50): small mixed clusters (likely doublets).

**Known limitation (harmonise.py):** all cortical neurons are labelled `Neurons (other)`; no cluster is called `Excitatory neurons` or `Inhibitory neurons`, although the paper defines ExN1-3 and InN1-3. The pan-neuronal marker score beats the excitatory/inhibitory sets in every neuronal cluster. ExN/InN-specific claims (e.g. chaperone changes in excitatory neurons) need a neuronal sub-labelling step before testing.
