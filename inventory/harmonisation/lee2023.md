## Sources and counts
- GSE148434 snRNA: 12 `GSM*_<donor>_snRNA.molecule_info.h5` (Cell Ranger molecule_info file_version 3, 32,738
  features). No count matrices are deposited. ATAC files are not used.
- **Counts rebuilt from molecule_info.** Each molecule entry is one unique barcode × UMI × feature after Cell Ranger's
  UMI correction and deduplication. Every entry whose barcode is in `barcode_info/pass_filter` adds 1 to
  X[barcode, feature], which reproduces how Cell Ranger builds its filtered matrix. Per-cell UMI = number of molecules.
- Pooled libraries (Table S1 pools 1–4: NOSN01/02/04, NOSN05/06, PDSN01/02, PDSN04/06/07) were deposited already
  split per donor (souporcell). Their molecule_info files contain only that donor's pass_filter barcodes: zero
  molecules fall outside pass_filter, and no pass_filter barcode is shared between donors of a pool (checked). The
  unpooled libraries (NOSN03, PDSN09) contain all barcodes, so molecules outside pass_filter were dropped
  (5.6 M and 4.2 M). The approach is reliable, but per-donor cells in pooled libraries depend on the authors'
  demultiplexing. Ambiguous or doublet droplets are presumably already removed.
- QC (uniform): >= 200 genes, < 10% mito.
- Metadata: Table S1 (`abo2467_Table_S1.xlsx`): diagnosis, APOE, age, sex, PMI, "Braak combo" (e.g. 4.2; meaning not
  defined in the table, kept as a string in `braak_combo`; braak_lb NaN), MMSE, DRS, snRNA pool. Region SN.
  disease: PD / control. PDSN02 has MMSE 0 but no dementia diagnosis is stated, so it stays PD.
